# Static website launch (no card, no subscription)

This is the **public informational prelaunch website** for The Service Margin — Cleaning Edition.

**Important:** Checkout is deliberately disabled. This repository contains **no paid downloadable product files**, card credentials or customer data. The business identity and legal pages need final professional review before sales. Paid sales and customer delivery are not configured.

## Free commercial-website hosting

Render could not create a site because the account requested payment information; no billing details were added or authorized.

The recommended alternative is **Netlify Free** (published free plan with a hard cap and permitted commercial usage). Owner action: create/log into Netlify using GitHub, choose Free, select **Add new project > Import an existing project > GitHub**, select `balaminacandles-dotcom/Service-margin-cleaning`, production branch `main`, **leave build command empty**, and set **publish directory to `.`** (repository root). Review that the selected plan is $0, no card, and no automatic paid upgrades. Click Deploy. The live link will be supplied by Netlify after successful deployment.

Do **not** use GitHub Pages for this business storefront: GitHub prohibits using Pages as free hosting to run an online business or e-commerce site.
